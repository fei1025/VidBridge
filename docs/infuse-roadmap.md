# VidBridge → Infuse 能力路线

目标不是复制 Infuse 的品牌或服务，而是逐步达到同一类产品体验：多来源接入、统一媒体库、稳定播放、元数据与海报、跨设备友好的播放状态，以及手机/平板/TV 的一致交互。

## 交付原则

1. 先稳定核心播放链，再扩展海报墙和在线服务。
2. 播放器、协议、媒体库和 UI 通过接口连接，页面不直接管理协议会话。
3. 每个阶段都保留可安装 APK，并用自动化测试和真实设备验收清单收口。
4. 外部服务器、真机硬解和长视频不能用 JVM 测试冒充完成。

## 阶段路线

### A. 播放核心重构

- libVLC 封装为 `PlayerEngine`，UI 不再直接创建 `LibVLC`/`MediaPlayer`；来源路径和 VLC 参数由独立 `PlaybackSourceResolver` 解析，页面只提交逻辑路径和播放偏好。
- 统一播放状态、轨道、错误、Seek、倍速、Surface 生命周期。
- 引入播放队列和连续播放，进度保存由播放会话统一负责。
- 为本地、SMB、WebDAV 使用统一 `PlaybackSource`，不在 UI 拼接协议 URI。

验收：三种来源均可播放；页面旋转、PiP、返回和重复进入不会泄漏播放器或文件句柄。

### B. 后台播放与系统控制

- 独立 `PlaybackService` 持有播放器实例。
- Android `MediaSession`、媒体通知、锁屏控制、耳机拔出、音频焦点和来电暂停。
- Activity 只连接播放会话并显示视频 Surface。
- 进程被回收后恢复最近播放项和位置。

验收：退到桌面、锁屏、切换应用后音频和控制仍然可用；返回应用可重新绑定视频画面。

### C. 媒体库与详情

- 扫描增量化：按文件指纹跳过未变化文件，支持取消、恢复和删除同步。
- 完善电影、剧集、季、集和不同质量版本的聚合模型。
- NFO/本地图片优先；TMDB 作为可选元数据提供方，密钥不进入数据库或日志。
- 海报/背景本地缓存、详情页、演员/简介/评分和错误回退。
- 收藏、继续观看、播放历史和同来源连续播放统一进入队列模型。

验收：1000+ 文件来源可扫描；重扫不重复创建条目；删除远端文件后媒体库可清理；电影和剧集详情可打开。

### D. 来源与网络质量

- WebDAV Range、重定向、认证、证书策略和断线恢复契约测试；Range 读取对临时 408/429/5xx 和连接超时执行有限次数退避重试，认证、权限和不存在文件不重试。所有非本地来源（SMB/WebDAV/SFTP/NFS/Jellyfin/Emby/Plex/DLNA）的已打开读取句柄在临时断线后会关闭旧句柄、重连并从原 offset 继续读取。
- SMB 会话重连、共享发现、中文/特殊路径和大文件 Seek 测试。
- 播放读取失败按错误类型重试，不对认证失败或文件不存在无限重试。
- 目录、元数据、图片和播放缓冲分层缓存；离线下载另建能力，不混入播放缓冲。离线下载首版已使用独立 Room v6 表、WorkManager、应用私有文件和 libVLC 本地文件播放，支持断点续传、暂停、重试和删除；Jellyfin/Emby/Plex 现在也通过带鉴权的 HTTP Range 读取句柄进入同一下载链路。

### E. Infuse 体验层

- 首页：最近播放、继续观看、来源、收藏和媒体库入口。
- 海报墙、筛选、排序、搜索、详情页和播放列表。播放列表已支持条目上移/下移，Room 顺序与播放顺序保持一致。
- 平板双栏布局、手势控制、Mini Player、PiP 和横竖屏策略。媒体库已在宽度 600dp 以上提供左侧海报网格与右侧详情预览，手机和 TV 保持原有导航行为；Android TV 首页启动时会把焦点放到继续观看或第一部媒体。
- Android TV 独立焦点导航；桌面组件只展示控制信息，不承载视频。

### F. 更多来源与发布

- NFSv3 AUTH_SYS 只读首版已接入；Jellyfin/Emby/Plex 使用独立服务器 API；DLNA 已接入仅限局域网地址的 SSDP 发现、设备描述解析、ContentDirectory SOAP Browse、DIDL-Lite 条目解析和资源 URL 直连播放。为兼容常见局域网 DLNA HTTP，Manifest 开启明文能力，但媒体协议代码拒绝公网 HTTP 端点。SFTP 已接入首次信任后变更拒绝，仍需真实服务器验收；DLNA 仍需真实设备验收。
- Release 构建、脱敏崩溃收集首版和 Macrobenchmark 模块已接入；设置页可分享最近一次脱敏报告，Release 已支持从环境变量/Gradle 属性读取签名配置；应用启动时会校正离线下载的 WorkManager 与文件状态，恢复被系统杀掉的任务，仍需在发布环境提供真实 keystore、外部收集端点、完成真机矩阵和 Play 发布检查。

## 当前基线

- 最近补齐：播放列表上下文已写入播放会话，进程恢复仍沿用原播放列表；播放器控制层提供队列菜单，可直接跳选列表条目，跨来源切换与自动连播共用同一队列。
- 最近补齐：媒体库增加“最近播放”页，包含已完成和未完成的播放记录，按最后播放时间排序，并复用现有进度、海报和来源信息。
- 最近补齐：播放列表支持带确认的整列表删除，Room 事务会同时清理列表条目，避免留下孤儿数据。
- 最近补齐：播放列表支持重命名，并在更新时刷新列表排序时间；新增、重命名、排序、删除均保持条目和媒体文件边界清晰。
- 最近补齐：媒体库支持带确认的清空播放历史，清理范围仅限 `playback_history`，并保留媒体库、收藏、下载和播放列表。

- 已有：来源管理、本地/SMB/NFSv3/WebDAV/SFTP/Jellyfin/Emby/Plex、Room v8、扫描、NFO、收藏、继续观看、播放列表、离线下载、libVLC 页面播放；删除来源时会取消扫描并清理该来源的下载、播放历史、播放列表条目和失效的最近播放会话，但保留列表本身与其他来源内容。媒体服务器、Plex 和 DLNA 的下载已接入统一 HTTP Range 句柄，支持和文件来源相同的 `.part` 断点、重试和原子提交，并兼容部分 DLNA 设备忽略 Range 的 200 响应。
- 已完成代码基础：播放核心抽象、Activity 绑定、后台播放服务、系统 MediaSession（含标题/时长元数据）、通知、音频焦点、耳机断开暂停和网络恢复重试；网络恢复重试会优先使用断网前的实时播放位置，不回退到旧的初始断点；libVLC 音轨/字幕选择、章节读取与跳转、音频/字幕延迟调节；播放页单击显示/隐藏控制层、即时倍速菜单、视频比例生效、同目录同名字幕自动匹配和手动外挂字幕导入；同剧集季集连续播放队列（电影不会串到同来源的无关视频），并支持播放页手动上一集/下一集且切换前保存进度；媒体库电影/剧集/视频筛选、剧集聚合、详情、质量版本选择、名称/年份/更新时间/大小排序、手机和平板自适应海报墙、跨来源海报磁盘缓存、Room v5 剧集分组字段、Room v7 导演/演员字段、Room v8 播放历史查询索引、季集详情列表、增量扫描复用、可选 TMDB 元数据/海报/背景/演职员补全、NFO 优先的元数据合并、TMDB 和本地背景图详情呈现、SMB/WebDAV 有限会话重建、HTTPS 强制、首页继续观看和媒体横向海报栏、海报墙播放进度、剧集卡片“播放剧集/自动连播”入口、详情页“从本集开始连播”提示、左右双击 Seek，以及 PiP 进入/退出时的控制层生命周期处理。
- 已完成体验层首版：播放列表独立使用 Room v5 的 `playlists`/`playlist_items`，支持新建、从详情加入、列表查看、播放和移除；不改变收藏、继续观看和自动连播数据。离线下载独立使用 Room v6 的 `downloads` 表和 WorkManager，使用 `.part` 临时文件完成原子提交，支持远端随机读取断点续传、本地来源离线复制、暂停/重试/删除、详情入口、下载列表和完成后的 libVLC 播放；媒体库已知文件大小会贯通到任务，下载开始即可显示总量并校验断点；播放会话现在会持久化本地下载路径，进程恢复时不会误切回远端来源；启动校正和下载列表都会检查实际文件，发现已完成文件缺失或长度不匹配时会标记失败并允许重试。媒体详情支持标记已看和清除当前播放进度。根导航已接入 Mini Player，复用后台 `PlaybackService` 的 libVLC 状态，支持离开全屏后的进度展示、暂停/继续、回到播放器和停止。桌面播放控制组件已接入，显示当前标题/进度/状态并提供打开应用、播放/暂停和停止操作，不承载视频 Surface。配置 TMDB Key 后媒体库会按电影/剧集分组自动补全，每次后台刷新最多处理 60 个没有有效缓存的条目，使用 7 天 TTL 和查无结果缓存，NFO/本地海报优先；应用启动时还会注册每 12 小时一次的后台元数据刷新，只有网络可用时执行，单条失败按 WorkManager 退避重试。播放设置已支持默认音轨/字幕语言代码，并由统一 `PlaybackSourceResolver` 转为 libVLC 选轨参数。已加入 Leanback 启动入口、TV banner、TV 焦点卡片、大屏媒体库网格首版，以及播放器 D-pad 左右 Seek/确认键播放暂停。应用启动时还会注册每 6 小时一次的启用来源自动刷新任务，受网络约束并复用可恢复扫描，不与手动扫描或离线下载混用。
- 尚未证明：实体设备上的硬解、锁屏和厂商后台限制、长视频/断网真机验证、真实 TV 遥控器体验、真实 NFSv3/SFTP/Jellyfin/Emby/Plex/DLNA 服务器认证与播放。Plex 媒体库已支持分区分页读取，真实大库仍待服务器验收；SFTP 首次信任和服务器换钥行为仍待真机验收；DLNA 需覆盖不同厂商的 SOAP、资源 URL 和鉴权行为。脱敏崩溃报告已能保存最近 5 次本地报告，但尚未接入正式外部收集平台。Macrobenchmark 已在 API 36 模拟器执行 1 项冷启动测试通过，仅证明测试链路可运行，不能替代实体设备性能数据。Release 产物已通过 64 位 ELF/ZIP 16 KB 检查，但正式签名仍待发布环境配置。
